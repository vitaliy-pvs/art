# CI/CD проекта Конфигуратор механизмов МШК

Проект является учебным.

Проект является копией проекта [Конфигуратор механизмов МШК](https://github.com/vitaliy-pvs/mchk) с добавлением CI/CD в учебных целях.

CI/CD проекта осуществляется в кластер K0s, развернутый на виртуальном сервере. IP-адресс виртуального сервера 217.28.222.73. Виртуальный сервер поддерживает SSH-соединение, логин guest, пароль 123.

Развернутый в кластере K0s сайт доступен по [ссылке](http://217.28.222.73/).

Проект написан на языке Python с использованием фреймворка Django.

Статус проекта - завершен.
